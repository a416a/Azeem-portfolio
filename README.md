# Muhammad Azeem Portfolio

A cinematic portfolio website for Muhammad Azeem, built with React, TypeScript, Vite, Tailwind CSS, Framer Motion, GSAP, and React Three Fiber.

## Commands

```bash
npm install
npm run dev
npm run build
npm run preview
npm run lint
```

## Project Structure

- `src/components/sections` - page sections such as hero, projects, skills, education, services, and contact
- `src/components/three` - animated Three.js background scene
- `src/data/portfolio.ts` - reusable portfolio content and contact links
- `public` - static images, icons, and favicon
